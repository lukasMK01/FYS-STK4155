# Project 1: Regression, Resampling, and Gradient Descent

**Course:** FYS-STK3155/FYS4155 Data Analysis and Machine Learning, University of Oslo
**Authors:** Esme Hookham, Lukas Monrad-Krohn, and Andrea Rosendahl

## Overview

This project studies regression on the one-dimensional Runge function. It
compares ordinary least squares (OLS), Ridge, and Lasso regression, and
investigates model complexity, the bias-variance tradeoff, bootstrap
uncertainty, cross-validation, and gradient-based optimization.

## Files

- `results_project1.ipynb` — main analysis notebook containing the calculations
  and plots for the project report. It covers OLS and Ridge, bootstrap and
  cross-validation, gradient descent and its variants, Lasso, and a final
  cross-validated model comparison.
- `Project1_tasks.ipynb` — course-provided project description and starter
  notebook.
- `playground.ipynb` — notebook for exploratory experiments.
- `FYS_STK_project1_report.pdf` — project report.
- `Project1.pdf` — project assignment.
- `*.png` — saved plots and figures from the analyses.

## Environment and running

Follow the shared environment setup in the
[repository README](../README.md). From this folder, open
`results_project1.ipynb` in Jupyter or VS Code and run its cells in order to
reproduce the analysis and figures. The other notebooks contain the project
prompt and exploratory work.
